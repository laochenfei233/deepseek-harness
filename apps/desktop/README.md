# dsh-desktop — DeepSeek Harness Desktop Client

English | [中文](README.zh.md)

A Tauri 2 desktop shell that embeds the dsh web UI in a native window, with a bundled Node runtime and a pruned dsh distribution: works out of the box, stays running when the window closes (tray resident), and restarts automatically if the service crashes. **It does not modify any upstream `packages/` / `apps/cli` code.** The four agent presets (`standard` / `code` / `minimal` / `cordis`) come from upstream unchanged.

## Architecture

```
src-tauri/            Rust shell
  src/dsh_runner.rs   dsh child-process lifecycle: spawn `dsh web --port 3081 --no-open`, port health probe, crash auto-restart (does not race when dsh-plugin restarts itself)
  src/tray.rs         tray residency: closing the window hides it; only tray Quit ends the process tree
  src/setup.rs        first-run wizard commands: write preset into the profile patch (agent-presets.config.default), install plugins (dsh plugin / local copy)
ui/dist/              shell frontend (pure static, no build): index.html full-window iframe + error banner; wizard.html first-run wizard
scripts/bundle-runtime.mjs  pack Node runtime + pnpm-deployed dsh closure + local plugins → runtime/
runtime/              packaging output (not committed; generated by CI; tauri.conf.json maps it as bundle resources)
```

Port contract: in-shell `dsh web` listens on `127.0.0.1:3081` by default; if that port is taken by another process, the shell scans upward for a free port (from 3082), passes `--port`, and delivers the actual port to the frontend via the `dsh://ready` event payload (the frontend no longer hardcodes an address). CLI `dsh web` still defaults to 3080. `/api` (including `host.openPath`, WebSocket downlink, SSE) is entirely served by dsh itself; the shell does not reverse-proxy. The shell does not render a top navigation bar — the interface is entirely the dsh UI; shell and iframe only exchange host-bridge messages (`source: 'dsh-desktop-host'` for notifications and external links).

## Development

Prerequisites: Node ≥ 22.19, pnpm ≥ 11, Rust ≥ 1.77, Tauri CLI (provided as a devDependency of this package).

```sh
pnpm install                # workspace dependencies
pnpm run build              # produce lib and apps/web/dist (static frontend for dsh web)
pnpm tauri dev              # from apps/desktop; dev mode uses PATH node + apps/cli/lib/bin.js
```

Dev mode needs built CLI artifacts (`pnpm run build`); you can also override runtime resolution with environment variables:
`DSH_DESKTOP_NODE` (node executable), `DSH_DESKTOP_DSH_BIN` (dsh CLI entry), `DSH_DESKTOP_PLUGINS_DIR` (local plugins directory).

## Building a release

```sh
pnpm run build              # repository artifacts
node scripts/bundle-runtime.mjs --platform win   # win|mac|linux; generates runtime/
pnpm tauri build            # package installers (runtime/ is bundled as resources)
```

CI (`.github/workflows/desktop-release.yml`) runs the same flow on a three-platform matrix and uploads to GitHub Release; trigger with a `v*` tag or manual dispatch.

## First launch

- Default preset: `standard` (changeable to `code` / `minimal` / `cordis`; written as `agent-presets.config.default` in `~/.dsh/profiles/web/cordis.patch.yml`)
- Default plugins: `dsh-plugin` (plugin center/market), `dsh-win-terminal-inspector` (Windows only; local copy + patch insert)
- Optional plugins: `dsh-better-sidebar`, `dsh-notification`, `dsh-session-context-menu`, `@xmanrui/dsh-im` (WeCom/Feishu/DingTalk/WeChat/QQ and 9 channels), `dsh-lark`, `dsh-qqbot`, `dsh-vision-router`, `graph-memory`, `aegis`

Plugin install/update/uninstall all go through official dsh mechanisms (`dsh plugin` / the dsh-plugin center); the runtime ships pnpm from the same version family.
